# Projekt: Aplikacja do planowania budżetu 
## Wymagania funkcjonalne
- Użytkownik tworzy swój profil wraz z danymi dotyczącymi budżetu oraz może je później edytować.
- Użytkownik dodaje i przegląda pojedyncze przychody oraz wydatki, podając ich kwotę, datę i opis.
- Użytkownik definiuje stałe przychody (np. wynagrodzenie) oraz wydatki stałe (np. rachunki, subskrypcje), a aplikacja automatycznie wyznacza datę ich kolejnej płatności.
- Użytkownik przypisuje dodawane wydatki do określonych kategorii (jedzenie, rachunki, rozrywka, zdrowie, transport, inne).
- Użytkownik tworzy cele oszczędnościowe z określoną kwotą docelową, dokonuje na nie wpłat oraz sprawdza postęp ich realizacji.
- Aplikacja automatycznie wylicza sumę przychodów, sumę wydatków oraz aktualne saldo
- Aplikacja blokuje próby wprowadzenia ujemnych kwot transakcji oraz wyświetla użytkownikowi komunikat o błędzie.
- Użytkownik obsługuje wszystkie funkcje programu za pomocą graficznego interfejsu okienkowego.
